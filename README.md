# CodeAlpha Supermarket Sales Analysis

## CodeAlpha Data Analytics Internship

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project focuses on **Exploratory Data Analysis (EDA)** and **Data Visualization** using a Supermarket Sales dataset.

## Tasks Completed

### Task 2 - Exploratory Data Analysis (EDA)

The dataset was analyzed to:

- Understand the dataset structure
- Check data types
- Check missing values
- Check duplicate values
- Perform statistical analysis
- Identify sales trends and patterns
- Identify potential anomalies

### Task 3 - Data Visualization

The following visualizations were created:

- Total Sales by Product Line
- Total Sales by Branch
- Payment Method Distribution
- Customer Rating Distribution
- Monthly Sales Trend

## Key Findings

- Total Transactions: 1,000
- Total Sales: 322,966.75
- Average Transaction Value: 322.97
- Highest Selling Product Line: Food and beverages
- Highest Selling Branch: Branch C
- Most Common Payment Method: Ewallet
- Average Customer Rating: 6.97
- Missing Values: 0
- Duplicate Rows: 0
